# 共有からタスクを追加する — 手動確認の手順

## ローカル（`npm run dev`）

1. ログイン済みで次を開く

   ```
   http://localhost:3000/tasks/share?text=テスト%20https%3A%2F%2Fexample.com%2Fa
   ```

   - 「リンク」に `https://example.com/a`、「メモ」に `テスト` が出る
   - タイトルが空のあいだ「追加」は押せない
   - タイトルを入れて「追加」→ `/tasks` に移り、追加したタスクが**すぐ**一覧に見える
   - そのタスクのリンクアイコンから `https://example.com/a` が開く。編集シートにメモ `テスト` が入っている
2. 同じ URL をもう一度開き、「買うもの」を選んで追加 → 買うものとして一覧に出る
3. 「追加」を素早く2回押す → タスクは1件だけできる
4. 「キャンセル」→ 何も追加されず `/tasks` に移る
5. `http://localhost:3000/tasks/share`（クエリなし）を開く → `/tasks` に移る
6. シークレットウィンドウ（未ログイン）で 1 の URL を開く → ログイン画面 → ログイン → 確認画面に戻り、リンクとメモが残っている

## Android 実機（本番）

manifest の変更がインストール済みのアプリに届くまで時間がかかることがある。出てこなければ、ホーム画面のアプリを削除して入れ直す。

7. Instagram の投稿 → 共有 → 一覧に Family App が出る → 選ぶと確認画面が開き、リンクに投稿の URL が入っている → 追加できる
8. X の投稿 → 共有 → Family App → リンクに投稿の URL、メモに本文（あれば）が入っている → 追加できる
9. Chrome でページを開き共有 → Family App → タイトルにページ名が入っている

## iPhone 実機（本番）

[ios-share-shortcut.md](ios-share-shortcut.md) のとおりショートカットを作ってから:

10. Instagram の投稿 → 共有 → `Family App に追加` → Safari で確認画面が開く（初回はログインを挟み、ログイン後に確認画面へ戻る）→ 追加できる
11. X の投稿でも同じく追加できる
12. ホーム画面の Family App を開く → 10・11 で追加したタスクが見える
